# Recommendation Profile Images

Place recommender profile images in this directory.

## Required Images

- `bhavishya-mandanna.jpg` - Bhavishya Mandanna profile photo
- `nikhil-r.jpg` - Nikhil R. profile photo
- `yifei-feng.jpg` - Yifei Feng profile photo
- `patrick-ferriter.jpg` - Patrick Ferriter profile photo
- `default-avatar.png` - Default placeholder avatar (fallback)

## Image Specifications

- **Format**: JPG or PNG
- **Recommended size**: Square aspect ratio (e.g., 200x200 pixels)
- **File naming**: Lowercase with hyphens matching the ID in data.ts
- **Background**: Professional headshot style

## Adding New Recommendation Images

1. Save the profile image in this directory
2. Name it to match the recommender's ID in `/components/Recommendations/data.ts`
3. Update the `profileImage` field in the data file
